# Despre noi

<div class="bg-gradient-to-r from-blue-50 to-indigo-50 p-6 rounded-lg mb-8">

**Zian Electric SRL** este o companie cu sediul în Alba Iulia, administrată de **Opriș Ioan Augustin**. Ne specializăm în instalații electrice conform normativ, servicii de climatizare și automatizare porți pentru case și apartamente.

**⚠️ Notă importantă**: Firma nu este autorizată. Avem program orar dinamic adaptat nevoilor clienților.

</div>
